GIT REFLECTION

1. Git is used for: Tracking changes in source code and managing version control locally.
2. GitHub is used for: Hosting repositories online, collaborating with teams, and sharing code projects.
3. A commit means: Saving a snapshot of your current staged changes with a descriptive message.
4. A branch is used for: Working on separate features or fixes independently without altering the main code.
5. A Pull Request is used for: Proposing and reviewing branch changes before merging them into the main codebase.
